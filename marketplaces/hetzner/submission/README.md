# Hetzner Cloud NetBird

NetBird is an open-source network security platform for secure,
WireGuard-based private networks. This image contains the dependencies and
release payload for a self-hosted NetBird control plane with its dashboard,
embedded identity provider, relay, and automatic HTTPS.

## Getting started

Create an Ubuntu 24.04 server from the NetBird snapshot with an SSH key and at
least 2 GB RAM. Point a public hostname to the server's IPv4 address. Supply
cloud-init generated by `render-user-data.sh`, or log in as root and complete
the guarded interactive setup.

Provisioning creates a limited sudo administrator, configures UFW and
Fail2ban, disables direct root SSH when requested, and verifies the public
dashboard and authenticated API. Access notes are stored in the limited
administrator's home directory.

Required inbound ports are TCP 22, 80, and 443 and UDP 3478. If a Hetzner
Cloud Firewall is attached, account for its stateless UDP behavior.
