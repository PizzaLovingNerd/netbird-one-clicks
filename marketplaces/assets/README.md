# Marketplace brand assets

`netbird-color.svg` is the NetBird mark from the official NetBird Dashboard
repository. `netbird-white.svg` is the single-color white marketplace variant
derived from that mark. Confirm both files with NetBird's brand owner before a
vendor submission; provider resizing or rasterization should preserve the
aspect ratio.

Recommended marketplace gradient colors:

- left: `#F68330`
- right: `#F05252`

Provider forms also require screenshots. Use current screenshots from the
release-candidate deployment rather than committing customer data or test
credentials to this repository.
